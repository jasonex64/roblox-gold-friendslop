# EXP-002 — T-030 night bank and manual rush validation

## Hypothesis and expected result (before Studio execution)

Approved D-037/D-039/D-040 timing creates a night-only rich digging option and
a manual rush without creating money or changing active sweep speed. Expect
the rich bank to reject new digs before night and at dawn, preserve existing
rich dirt's multiplier, accelerate remaining dig work at rush, use short
sweeps only when their own start is at/after rush, and reject production/sales
at the exact bell. Replay must restore day/closed bank and normal speed.

## Method

Use the same t011-alerts-playtest.rbxl through Rojo and Studio connectors.
Run tests/studio/NightRush.luau in solo and a temporary two-client session.
The fixture uses isolated controllers, a supplied clock and actual avatars;
it is not a human or natural-duration test. Run a live client journey using
real remotes for ordinary production and daytime rich-bank rejection. Inspect
the HUD with clearly labelled client-only phase previews, then restore state.
Pure tests cover exact boundaries, early-hit rescheduling, source preservation
and cutoff. All gameplay numbers are the approved Config values.

## Results

Passed in the same place on 2026-10-24. `NightRush.luau` passed with one
and two actual avatars: night/dawn boundaries, rich dirt transfer and provenance,
$7 conserved sale, active versus next rush sweep, accelerated dig, exact bell
rejection, discard and replay reset. These are injected-time service fixtures.
`CrewJourney.client.luau` passed via live remotes: $5 sale and personal share.
A live daytime rich-bank dig request created no dirt and exposed no dig action.
Desktop day/rush previews were readable. The first 375px HUD preview reported
TextFits=false; increased the narrow timeline height and moved narrow toasts.
The corrected 375px preview passed TextFits for day/night/dawn/rush and showed
the discard text. Phase previews only changed client attributes, not server time;
Play was stopped to restore state. Same place remains open in Edit with Rojo.
Existing asset 203785492 type warnings appeared; no gameplay errors occurred.
Human Gate C acceptance belongs to T-034.
