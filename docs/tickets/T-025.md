## Goal
`src/shared/Pure/Timeline.luau` answers the time questions Gate C needs: which shift phase it is, whether the rich night bank accepts digging, and when processing started at a given moment finishes once the final rush speeds it up.
Source: DESIGN §4 (ten-minute shift), §15 Gate C. First Gate C piece; pure so it runs in parallel with T-021.

## Why
Who uses it: the later Gate C wiring ticket (night bank pad, rush timers, HUD countdown).
What breaks without it: phase edges and rush timing end up scattered across server timers where off-by-one and mid-process speedups are hard to test.

## Acceptance criteria
- [x] `phase(elapsed, config)` returns day, night, dawn, rush or ended with inclusive start edges — test: TIME-1
- [x] `canDig(source, elapsed, config)` admits the rich source only during night and always admits other sources; already dug dirt is unaffected because Batch stores its multiplier at dig — test: TIME-2
- [x] `finishAt(start, baseSeconds, config)` applies the rush speedup only to the part of processing after the rush starts — test: TIME-3, TIME-4
