## Goal
`src/shared/Pure/Run.luau` owns run phases and the end/reset order, so T-005 and T-009 only wire it to the server clock.
Source: DESIGN §4, 12-13, 15 (Gate A).

## Why
Who uses it: T-005, T-009.
What breaks without it: end-of-run ordering bugs (double sale, carried state) are untestable in Studio.

## Acceptance criteria
- [x] `new(runId, now, config)` waits for the ready condition, then runs until `start + shiftSeconds`; `accepts(run, now)` is false outside running — test: RUN-SM-1
- [x] `finish(run)` returns ordered steps: stop production, sell completed, discard unprocessed, freeze result; calling twice errors — test: RUN-SM-2
- [x] `reset(run)` returns a fresh run with a new id and no carried values — test: RUN-SM-3
