## Goal
Game code lives as files in git and syncs into Roblox Studio, and tests run from one command.

## Why
Who uses it: all three humans and every agent.
What breaks without it: agents can't read or diff code that only exists inside a .rbxl place file, so nothing else in this workflow works.

## Acceptance criteria
- [ ] Decision recorded as a D-### naming the sync tool and test runner, with the reason — test: manual, D-### exists
- [ ] Fresh clone → documented steps → code appears in Studio — test: manual, run by a second human on their own machine
- [ ] One failing and one passing example test, run by one documented command — test: run it, failing test exits non-zero

## Out of scope
- Any game code
- CI pipelines
- Linting/formatting config beyond what the chosen tools require

## Numbers used
- none
