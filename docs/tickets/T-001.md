## Goal
Game code lives as files in git and syncs into Roblox Studio, and tests run from one command.

## Why
Who uses it: all three humans and every agent.
What breaks without it: agents can't read or diff code that only exists inside a .rbxl place file, so nothing else in this workflow works.

## Acceptance criteria
- [x] Decision recorded as a D-### naming the sync tool and test runner, with the reason — test: manual, D-009 exists
- [ ] Fresh clone → documented steps → code appears in Studio — test: manual, run by a second human on their own machine
- [x] One failing and one passing example test, run by one documented command — test: `lune run scripts/check` runs `tests/selftest` and requires exit 1 with 1 passed, 1 failed
- [x] CI runs the Luau gate on every PR and push to main — test: `luau` job in checks.yml green on this PR
- [x] AGENTS.md tells agents how to use Rojo, the Studio MCP, Pure modules, and `assets/` — test: manual, read AGENTS.md
