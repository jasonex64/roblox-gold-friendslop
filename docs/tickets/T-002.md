## Goal
Codex and Claude agents read one shared rule file, and any change that skips its ticket Log entry fails loudly.

## Why
Who uses it: all three humans' agents (Claude Code and Codex).
What breaks without it: main is unprotected (decision D-001), so an agent can push undocumented changes and nothing notices.

## Acceptance criteria
- [x] AGENTS.md exists at repo root, points to WORKFLOW.md, lists hard rules — test: manual, read it
- [x] CLAUDE.md imports AGENTS.md so Claude Code gets the same rules — test: manual, file contents
- [x] `tools/check_docs.py` exits 1 when a commit has no `T-###:` prefix — test: CHK-1
- [x] `tools/check_docs.py` exits 1 when a commit changes files outside its ticket file but the ticket Log has no new entry in the range — test: CHK-2
- [x] `tools/check_docs.py` exits 0 for a documented change — test: CHK-3
- [ ] GitHub Action runs board.py + check_docs.py on every PR and every push to main — test: manual, Action run visible on this ticket's PR
- [x] D-001 records "main is unprotected" and why — test: manual, DECISIONS.md
