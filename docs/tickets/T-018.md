## Goal
Agents can build and edit custom meshes and animations in Blender through Blender MCP, reproducibly from scripts in the repo, so the art pass can replace Gate A's placeholder parts.
Not needed before Gate A is validated (T-011). Nothing in M1 depends on this ticket.

## Why
Who uses it: all three humans' agents during the art pass.
What breaks without it: props stay gray boxes, and the Studio MCP cannot author animations (dig, sift).

## Acceptance criteria
- [ ] README has optional Blender setup: Blender 3+, Python 3.10+, `uv`, Blender MCP add-on, `DISABLE_TELEMETRY=true`, safe mode on, socket on localhost only — test: second human follows it on their machine
- [x] `tools/blender/<name>.py` builds a model from scratch; running it twice gives identical exported geometry — test: BLEND-1
- [x] Exports go to `assets/meshes/` via Git LFS, each under 20,000 triangles — test: BLEND-2
- [x] AGENTS.md rule: commit the generator script, a human uploads to Roblox, asset ID recorded in `Config.luau` with a citation — test: manual, read AGENTS.md
- [ ] One real prop (e.g. gold pan) goes script → export → human upload → visible in a Studio MCP playtest — test: BLEND-3

## Out of scope
- Making Blender required for anyone
- Hand-made `.blend` files without a generator script
- Agents uploading to Roblox

## Numbers used
- 20,000 triangles: Roblox mesh limit, https://create.roblox.com/docs/art/modeling/specifications

## Test plan
BLEND-1: run the generator twice, compare exported files' hashes. BLEND-2: script counts triangles per export; `git lfs ls-files` lists them. BLEND-3: MCP `screen_capture` of the prop in a playtest; paste asset ID and console into Log.
