## Goal
`src/shared/Pure/Ledger.luau` does all Gate A money math: atomic sale, purchase, Crew Haul, solo wallet.
Source: DESIGN §6-8, 13; D-002, D-003, D-007.

## Why
Who uses it: T-008, T-009.
What breaks without it: money bugs (double sale, haul reduced by spending) land in server code.

## Acceptance criteria
- [ ] `sell(ledger, finds, requestId)` marks finds sold once, adds base values to haul and wallet; a repeated requestId changes nothing — test: LEDGER-1
- [ ] `buy(ledger, item, requestId)` checks affordability and prerequisites, deducts once, never reduces haul; rejection leaves the ledger unchanged — test: LEDGER-2
- [ ] Selling an already-sold or unknown find errors by name — test: LEDGER-3
