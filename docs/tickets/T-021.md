## Goal
Players contribute personal cash toward one shared machine and manually process shared dirt.

## Acceptance criteria
- [x] Humans approve price, processing timing, capacity, funding and output ownership rules; cite Config values.
- [x] Server uses T-023's pure transactions (no overcharging, duplicate builds or duplicate processing); funding does not reduce Crew Haul.
- [x] Two nearby controls provide quick Bucket-to-sluice/sluice-to-Backpack transfer and a stats interface. Twenty total dirt (queued plus processing) feeds the lanes; no direct shared-bin loading; output pauses safely when full; upgrades deferred per D-036.
- [x] Only collected Backpack finds can be sold through T-019 payouts; cutoff discards unsold/unfinished output without payment; replay resets machine and funding.
- [x] Studio solo/crew evidence and all repository gates pass.

## Out of scope
Hopper automation, extra tiers, night/rush modifiers, classes and pets.

## Test plan
Use focused pure tests, server integration checks and existing-place Studio MCP evidence. Follow AGENTS.md gates. No invented human validation.
