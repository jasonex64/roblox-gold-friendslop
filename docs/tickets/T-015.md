## Goal
`src/shared/Pure/SkillCheck.luau` grades a timing input (DBD-style, D-008) from a needle position and a target zone, so the server never trusts the client's verdict.
Source: D-008; ND39; DESIGN §5.

## Why
Who uses it: T-007.
What breaks without it: the skill check would be graded on the client or with untested math.

## Acceptance criteria
- [x] `start(now, config, rng)` returns a check with zone start/width and needle speed from config, zone placed by injected rng — test: SKILL-1
- [x] `grade(check, pressTime)` returns `success`, `miss`, or `expired` from elapsed time alone; boundaries are inclusive and tested — test: SKILL-2
- [x] Grading the same check twice errors (no rerolls) — test: SKILL-3

## Out of scope
- What success/miss does to the batch (T-004 DEC-3, then T-007)
- UI

## Numbers used
- Pure module rules in AGENTS.md. Test values in specs are fixtures, not gameplay numbers.

## Test plan
`tests/unit/SkillCheck.spec.luau` covering SKILL-1..3, including exact zone edges.
