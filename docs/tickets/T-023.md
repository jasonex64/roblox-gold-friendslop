## Goal
`src/shared/Pure/Sluice.luau` decides crew funding, lane loading, processing and shared output for one tier-one sluice, so T-021 only wires it to the server and HUD.
Source: DESIGN §8 (shared machinery). Split from T-021 so it runs in parallel with T-020.

## Why
Who uses it: T-021.
What breaks without it: overcharging, double builds and double processing get built into server code where they are hard to test.

## Acceptance criteria
- [x] `contribute` charges a personal wallet at most the remaining price, builds exactly once when fully funded, rejects insufficient funds and repeated request IDs with unchanged state, and never touches Crew Haul — test: SLUICE-1, SLUICE-2
- [x] `load` rejects an unbuilt sluice, busy lanes, full output and an already-processed batch; a batch is processed at most once — test: SLUICE-3, SLUICE-5
- [x] `collect` moves batches to shared output exactly when their processing time ends; `take` removes output once — test: SLUICE-4, SLUICE-6

## Out of scope
- Roblox wiring, HUD, Config values, bin transfers, hopper and tier two (T-021 and later)

## Numbers used
- Pure module rules in AGENTS.md. Price, lanes, timing and output capacity are injected; test values in specs are fixtures, not gameplay numbers.

## Test plan
`lune run tests/run unit` with `tests/unit/Sluice.spec.luau` covering SLUICE-1..6.
