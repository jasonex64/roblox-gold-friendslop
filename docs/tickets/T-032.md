## Goal
Let the crew fund a second sluice upgrade that speeds every lane, and make lanes use the final-rush speedup.

## Why
Who uses it: crews that built the sluice early. What breaks without it: no machine upgrade decision after the build (DESIGN §8), and lanes ignore the rush.

## Acceptance criteria
- [x] Config cites D-043 for the tier-two price and speed
- [x] Funding works like D-035: capped, built once, personal wallets, never lowers Crew Haul; only after the sluice is built
- [x] Lanes loaded after the upgrade use the new speed; lanes use `Timeline.finishAt` so the rush applies only to work after 9:00
- [x] Sluice stats show the upgrade instead of "Upgrades coming later"; bell and replay reset it
- [x] Studio solo/crew evidence and all gates pass

## Files
Pure Sluice/Machine, Machinery, SluicePanel, Config. Does not touch Digging or Sifting.

## Decisions
- D-043: tier two is 250 x N for 2.5 s per dirt, funded under D-035 after the sluice is built.

## Out of scope
Hopper (T-033), more tiers.

## Test plan
Pure tests for new rules, then existing-place Studio MCP fixtures and a live journey. Follow AGENTS.md gates. No invented human validation.
