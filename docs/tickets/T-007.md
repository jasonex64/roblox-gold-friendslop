## Goal
The player sifts carried dirt at the river through the D-008 skill check (graded by T-015) and gets completed finds.
Source: DESIGN §4-5, 8, 12-14 (Gate A, R02/R12); D-008; ND39.

## Why
Who uses it: the player and selling.
What breaks without it: dirt could be consumed without output space, or animation could grant loot.

## Acceptance criteria
- [x] Sifting needs a valid batch and reserved output space, snapshots the rate at start, and excludes digging — test: SIFT-1
- [x] Only server completion produces the batch's assigned find; no extra crate payout — test: SIFT-2
- [x] Cancel, reset, full output, and run cutoff never duplicate or reroll a batch and release reservations; cancel discards active dirt (D-014/015) — test: SIFT-3
- [x] Completed finds show name plus visual/audio feedback; client completion grants nothing — test: SIFT-4
- [x] Skill-check result comes from T-015 on the server; its effect uses approved D-015 Config values — test: SIFT-5

## Out of scope
- Sluice/hopper, discovery book, premium luck

## Numbers used
- Values come from `src/shared/Config.luau` (D-011): approved `D-###`, else `PROVISIONAL DESIGN §N`. Gate A inventory: T-003 ND list.

## Test plan
SIFT-1..4: `execute_luau` drives full/empty capacity, cancel at each step, and a fake client completion; inspect server state. SIFT-5: send success, miss, invalid, and cancelled inputs; batch identity never changes.
