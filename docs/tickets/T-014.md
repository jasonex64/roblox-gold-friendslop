## Goal
`src/shared/Pure/Batch.luau` decides whether a dig may create a batch and assigns its outcome once, so the server wiring (T-006, T-007) has nothing to get wrong.
Source: DESIGN §5, 8, 13 (batch states).

## Why
Who uses it: T-006, T-007, T-008.
What breaks without it: duplication and reroll bugs get built into server code where they are hard to test.

## Acceptance criteria
- [x] `create(state, request, config, rng)` rejects wrong phase, out-of-range distance, full capacity, and over-rate requests with a named reason and unchanged state — test: BATCH-1
- [x] A created batch has id, source, digger, and an outcome drawn once from injected rng; cancel/retry keeps the same outcome — test: BATCH-2
- [x] State moves only queued → processing → completed → sold; any other transition errors — test: BATCH-3

## Out of scope
- Roblox wiring, UI, odds values

## Numbers used
- Pure module rules in AGENTS.md. Test values in specs are fixtures, not gameplay numbers.

## Test plan
