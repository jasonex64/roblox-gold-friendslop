## Goal
Before the crew sluice is built, standing at it offers "fund sluice" as the main action (E or tap) and opens the funding panel; after it is built, the main action returns to quick transfer with the stats button.
Source: jason's T-021 re-review note (a); DESIGN §6 (show price, funding and contributors on the pad). Needed for the T-022 human playtest, step 3.

## Why
Who uses it: every crew in the T-022 playtest.
What breaks without it: the only visible action before building is quick transfer, which just says to fund first; funding is hidden behind the Sluice stats button.

## Acceptance criteria
- [x] `Hud.nextAction` returns `fund_sluice` at the sluice while it is unbuilt and `open_sluice` once built — test: SLUICE-UI-1
- [x] The server tells Hud whether the sluice is built; the client opens the funding panel for `fund_sluice` and shows the Sluice stats button only for `open_sluice` — test: Studio live journey
- [x] All repository gates pass
