## Goal
The server records each player's digging, sifting, sluice loading, selling and sluice funding with T-026's Contributions module, and the end-of-shift results screen lists one line per player.
Source: DESIGN §4 (result screen shows each player's useful contributions), §6 (record them separately), §15 Gate C.

## Why
Who uses it: every crew at the bell; T-022 playtesters judging whether teammates helped.
What breaks without it: the results screen shows only Crew Haul, so nobody can see who dug, sifted or funded.
