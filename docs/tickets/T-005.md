## Goal
A player enters a placeholder river camp (bank, river, camp, buyer) with starter gear, and the server runs one shift using the T-017 run state machine.
Source: DESIGN §4-5, 13-15 (Gate A, R02/R12).

## Why
Who uses it: the player and every gameplay system.
What breaks without it: no shared run identity, clock, or place to play.

## Acceptance criteria
- [ ] Layout built from code (or `.rbxm` in `assets/`) loads through Rojo with unobstructed routes; direct entry into the run place — test: RUN-1
- [ ] Server owns run ID, start, and end via T-017; actions before start and after cutoff are rejected — test: RUN-2
- [ ] Starter loadout and timings read only from Config.luau with a rules version; a missing required value errors by name — test: RUN-3

## Out of scope

- Classes, pets, purchases, persistence
