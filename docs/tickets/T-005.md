## Goal
A player enters a placeholder river camp (bank, river, camp, buyer) with starter gear, and the server runs one shift using the T-017 run state machine.
Source: DESIGN §4-5, 13-15 (Gate A, R02/R12).

## Why
Who uses it: the player and every gameplay system.
What breaks without it: no shared run identity, clock, or place to play.

## Acceptance criteria
- [x] Layout built from code (or `.rbxm` in `assets/`) loads through Rojo with unobstructed routes; direct entry into the run place — test: RUN-1
- [x] Server owns run ID, start, and end via T-017; actions before start and after cutoff are rejected — test: RUN-2
- [x] Starter loadout and timings read only from Config.luau with a rules version; a missing required value errors by name — test: RUN-3

## Out of scope
- Lobby, reserved servers, matchmaking, reconnect, night/rush events
- Classes, pets, purchases, persistence

## Numbers used
- Values come from `src/shared/Config.luau` (D-011): approved `D-###`, else `PROVISIONAL DESIGN §N`. Gate A inventory: T-003 ND list.

## Test plan
RUN-1: MCP playtest, `screen_capture` + `search_game_tree` show the layout and gear. RUN-2: `execute_luau` sends actions before/during/after the run; expect accept/reject per T-017. RUN-3: remove a required Config value; expect a named error.
